# HIVE pilot packages

Pricing is editable commercial guidance and never runtime behavior. Final scope, fees, taxes, travel, support, and acceptance terms belong in a signed proposal.

## HIVE Setup

Outcome: one engineer can run HIVE safely on one repository.

- Local installation and version verification
- BYOK or local-provider configuration without copying secrets into project files
- One repository safety-policy configuration
- Baseline coding session and run report
- One handoff session and setup notes

Example duration: 1–3 working days. Excludes custom role development, hosted execution, and remediation of unrelated repository failures.

## HIVE Workflow

Outcome: a repeatable repository-specific verified engineering loop.

- Setup deliverables
- Custom role instructions and provider/model routing
- Repository presets, file boundaries, approvals, validation, and review workflow
- Three representative task trials
- Cost/performance baseline and recommendations

Example duration: 1–2 weeks. Acceptance is based on agreed trial tasks and evidence, not guaranteed autonomous completion of arbitrary work.

## HIVE Team Pilot

Outcome: evidence for a team adoption decision across multiple repositories.

- Workflow deliverables for an agreed repository set
- Shared workflow design and GitHub integration planning
- Team onboarding and operator runbook
- Measured pilot task set and weekly review
- Final evaluation report, risks, and rollout recommendation

Example duration: 3–6 weeks. Organization accounts, hosted RBAC, managed credits, and production GitHub App implementation are excluded.

## Commercial placeholders

Use fixed-fee discovery plus package fee where scope is stable; otherwise use capped time-and-materials. Quote provider usage separately as customer-owned BYOK cost. Never present estimated model cost as an invoice-grade value.
